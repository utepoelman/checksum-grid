Kia ora tamariki! Ko Nugget tōku ingoa.

I’m Nugget! Follow my 4 steps below to complete your grid and find your secret Grand Total.

  1. 1

    Solve Every Box

    Write the answer to each question neatly inside its grid square.

  2. 2

    Add Across Each Row

    Add the numbers in each horizontal row and write the Row Total in the shaded box on the right.

  3. 3

    Add Down Each Column

    Add the numbers in each vertical column and write the Column Total in the shaded box at the bottom.

  4. 4

    Verify Your Grand Total

    Add all Row Totals together, then add all Column Totals together. When both match, write your Grand Total in the corner box!
